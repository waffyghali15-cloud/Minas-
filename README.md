# Minas-# ✨ Minas Magic Math

تطبيق تعليمي تفاعلي لتعليم الأطفال قواعد الجمع والطرح بطريقة "أصدقاء العدد" — بدون حفظ، بفهم ومتعة!

## 🎯 المميزات

- 🎮 **6 ألعاب تفاعلية** — أصدقاء 5، أصدقاء 10، سرعة الحساب، الرقم المختفي، البالونات، المطابقة
- 📚 **قواعد الجمع والطرح** — شرح واضح لقواعد أصدقاء 5 و 10
- 📅 **خطة تدريسية شهرية** — 12 درس مقسمة على 4 أسابيع
- ⏱ **تايمر للخطوات** — مع صوت رنين واهتزاز
- 🏆 **نظام النجوم والإنجازات** — لتحفيز الطلاب
- 💾 **حفظ التقدم** — localStorage يحفظ إنجازاتك
- 📱 **يعمل offline** — لا يحتاج إنترنت
- 🔊 **صوت رنين للتايمر** — Web Audio API

## 🚀 كيفية الاستخدام

1. افتح الملف `index.html` في أي متصفح
2. أو ارفعه على GitHub Pages ليصبح موقعاً مباشراً
3. أو استخدمه في AppsGeyser لتحويله لتطبيق Android

## 📱 AppsGeyser

لتحويل التطبيق لـ APK:
1. اذهب إلى [appsgeyser.com](https://appsgeyser.com)
2. اختر "Create App" → "Website"
3. ارفع ملف `index.html`
4. سمِّ التطبيق واختار الأيقونة
5. اضغط "Create" — جاهز!

## 🛠 التقنيات المستخدمة

- HTML5
- CSS3 (بدون أي إطارات خارجية)
- JavaScript (Vanilla JS)
- Web Audio API (لصوت الرنين)
- localStorage (لحفظ التقدم)

## 📝 ملاحظات

- لا يوجد أغاني — فقط صوت رنين بسيط للتايمر
- يعمل offline 100%
- لا يحتاج أي ملفات خارجية
- متوافق مع جميع المتصفحات والموبايل
